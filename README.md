# Python for Data Science Notebook

This repository contains my Jupyter notebooks with the course content and lab exercises of **[Python for Data Science (PY0101EN)](https://cognitiveclass.ai/courses/python-course-applied-data-science)**, provided by **IBM** and completed on **Cognitive Class (cognitive.ai)** — part of the **IBM Skills Network**.

The notebooks cover Python fundamentals through working with data, NumPy, APIs and HTTP requests, following the full curriculum of the course.

## 📚 Course Modules Covered

### Module 1 — Python Basics
| Notebook | Topics |
|----------|--------|
| `PY0101EN-1-1-Write_your_first_python_code.ipynb` | Writing your first Python program, types (int, float, str), expressions and variables, string operations |
| `PY0101EN-1-2-Strings.ipynb` | Strings: indexing, slicing, escape sequences, string methods, find/replace, formatting |

### Module 2 — Python Data Structures
| Notebook | Topics |
|----------|--------|
| `PY0101EN-2-1-Tuples.ipynb` | Tuples: indexing, slicing, nesting, sorting |
| `PY0101EN-2-2-Lists.ipynb` | Lists: indexing, methods, mutable vs immutable, cloning vs aliasing |
| `PY0101EN-2-3-Sets.ipynb` | Sets: operations (union, intersection, difference), subset/superset checks |
| `PY0101EN-2-4-Dictionaries.ipynb` | Dictionaries: keys, values, adding/removing entries |

### Module 3 — Python Programming Fundamentals
| Notebook | Topics |
|----------|--------|
| `PY0101EN-3-1-Conditions.ipynb` | Conditions & branching: comparison logic operators, if/elif/else |
| `PY0101EN-3-2-Loops.ipynb` | Loops: for & while loops, range(), enumerate(), break/continue |
| `PY0101EN-3-3-Functions-jupyterlite.ipynb` | Functions: defining functions, parameters, return values, scope |
| `3-1 2ExcecptionHandling.ipynb` | Exception handling: try/except, error types, graceful failure |
| `PY0101EN-3-4-Classes.ipynb` | Objects & classes: object-oriented programming, classes, instances, methods, attributes |

### Module 4 — Working with Data
| Notebook | Topics |
|----------|--------|
| `PY0101EN-4-1-ReadFile.ipynb` | Reading files with open(), read/readline/readlines, with statement |
| `PY0101EN-4-2-WriteFile.ipynb` | Writing files with open(), write modes, copying files |
| `PY0101EN-4-3-LoadData.ipynb` | Loading data with Pandas: DataFrames, read_csv, head/tail, unique values |

### Module 5 — Numpy Arrays, APIs & HTTP
| Notebook | Topics |
|----------|--------|
| `PY0101EN-5-1-Numpy1D.ipynb` | NumPy 1D arrays: array creation, slicing, vectorized operations, universal functions, dot product |
| `PY0101EN-5-2-Numpy2D.ipynb` | NumPy 2D arrays: matrices, element-wise vs matrix multiplication, transpose |
| `PY0101EN-5 2_API_2 v2-Copy1.ipynb` | Application Program Interfaces (APIs): REST APIs, API keys, GET/POST requests |
| `PY0101EN-5 3_Requests_HTTP.ipynb` | HTTP protocol using the Requests library: GET requests, URL structure, response headers/body |

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Armor48/Python-for-Data-Science-Notebook.git
cd Python-for-Data-Science-Notebook
```

2. Install the dependencies:

```bash
pip install numpy pandas requests jupyter
```

3. Launch Jupyter and open any notebook:

```bash
jupyter notebook
```

Run the notebooks in module order (1 → 5) to follow the course curriculum from Python basics to APIs and HTTP.
